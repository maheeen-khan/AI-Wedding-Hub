
## Vendors
```
GET    /api/vendors
GET    /api/vendors?category=venue
GET    /api/vendors?city=Karachi
GET    /api/vendors?is_recommended=true
GET    /api/vendors?search=marquee
GET    /api/vendors/:id
POST   /api/vendors
PUT    /api/vendors/:id
DELETE /api/vendors/:id
```
