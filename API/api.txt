
## Vendor Listing APIs
```
GET /api/vendors/:category
→ Get all vendors by category
→ Examples:
  /api/vendors/venue
  /api/vendors/catering
  /api/vendors/photography
  /api/vendors/decor
  /api/vendors/makeup
  /api/vendors/car-rental
```

---

## Vendor Profile API (Single Vendor — Full Details)
```
GET /api/vendors/:category/:id
→ Get single vendor full profile
→ Returns everything in one call:
  name, location, rating, images,
  tags, amenities, reviews, faqs,
  category specific details
→ Examples:
  /api/vendors/venue/1
  /api/vendors/catering/4
  /api/vendors/photography/7
  /api/vendors/decor/10
  /api/vendors/makeup/13
  /api/vendors/car-rental/16
```

---

## How Dynamic IDs Work
```
Step 1 → Call listing API
  GET /api/vendors/venue
  → Returns all venues with their real DB ids
  { id: 1, name: "Sensational Marquee" }
  { id: 2, name: "Royal Marquee" }
  { id: 3, name: "Grand Palace" }

Step 2 → Use real id in card link
  <Link to={`/Vendor_Profile_Page/venue/${venue.id}`}>

Step 3 → Profile page calls detail API
  GET /api/vendors/venue/2
  → Returns full profile of that vendor
```
